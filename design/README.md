# Design source

Derived from one physical copy of ICONS (Zak Group for Virgil Abloh and Nike, Taschen, 2021), photographed by Scott Campbell on his desk with an iPhone, 2026-10-13 and 2026-10-14. One layer removed: the object, not the page layouts. Typefaces in the book are ABC Diatype and ABC Monument Grotesk Mono (fontsinuse.com/uses/43029); the site uses Helvetica Neue and Courier New, system only.

`source/` holds the frames the tiles were cut from. `scripts/cut-tiles.py` reproduces `public/textures/`.
